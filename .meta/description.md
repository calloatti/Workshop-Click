Ever wanted to quickly check a mod's page to read the patch notes or remind yourself what it does? This mod makes it seamless.

### Features
Now also works with Workshop maps.
Quick Access: Simply click the cloud icon of any downloaded Workshop mod in the in-game Mod Manager.
Steam Overlay Integration: Instantly opens that mod's Steam Workshop page directly in the Steam Overlay.
Option to open links in the default browser instead of the Steam overlay.
Supports Mod Manager, local mods with a mod_manager_manifest.json file will open Mod.io mod page.
The click action is strictly tied to the mod's cloud/folder icon, so you can still easily toggle checkboxes and change load priorities without accidentally opening the overlay.

### Settings:
Settings - Mod Settings (settings are saved in \PlayerData)
